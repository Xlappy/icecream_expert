# Звіт про внесені зміни (Сесія 08.01.2026)

## 1. Архітектурні зміни (Backend)
- Впроваджено базу даних **SQLite** (`backend/database.sqlite`) для надійного зберігання даних.
- Створено **Node.js/Express** сервер (`backend/server.js`) як API-прошарок.
- Написано скрипт міграції (`backend/seed.js`), який переніс 130+ записів морозива з коду до SQL-таблиці.
- Реалізовано повнотекстовий пошук за допомогою SQL-запитів `LIKE` (`/api/search`).

## 2. Дизайн та Інтерфейс (Frontend)
- **Концепція**: Перехід до стилістики "Retro Diner 50's" (Ретро-забігалівка).
- **Технології**: Tailwind CSS + Custom CSS Variables.
- **Шрифти**: Shrikhand (заголовки) та Quicksand (текст).
- **Palette**: `diner-pink` (фон), `diner-blue` (акценти), `choco` (текст), `cherry-red` (кнопки).
- **Стиль UI**: Neubrutalism (жирні рамки 4-8px, жорсткі тіні без розмиття, фірмова клітинка `checkerboard`).

## 3. Функціональні вдосконалення
- **Навігація**: Впроваджено нестандартне бокове меню праворуч у вигляді "чеків" замовлень.
- **Пошук**: Пошук тепер працює виключно в режимі "Каталог" (Database), що логічно для бізнес-додатка.
- **Фільтрація**: Додано швидкий фільтр по ціні (slider) у вікні каталогу.
- **Виправлення**: Пошук тепер коректно комбінується з обраною категорією та лімітом ціни.
- **Оптимізація**: Прибрано зайвий неон та візуальний шум ("New" баджі), що заважали сприйняттю.
