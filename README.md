# IceExpert - Professional Gourmet Guide

This is a professional expert system for ice cream and dessert recommendations, featuring a sophisticated ranking algorithm based on user preferences.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
